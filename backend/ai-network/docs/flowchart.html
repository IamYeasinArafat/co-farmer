How Hydro Monitor works

Sensors in each bed report to a master node, which logs every reading and switches the pumps to keep conditions inside safe ranges. Every 6 hours, a CrewAI agent network on the laptop reads the farm's data and the forecast. It sets new ranges for the master, and writes advice for the farmer in Arabic and English. Before any of that, an onboarding assistant designs the hardware and the network for the farm.

The two parts

Green is the IoT part in the fields; it runs the farm on its own. Magenta is the agentic part on the laptop; it sets the ranges the master enforces. Two small formats connect them: log rows going up, ranges coming down.

One agent run

Code does the counting; the agents do the judging; code checks the result before the master sees it. Each department is a CrewAI agent that replies in a fixed JSON format. It gets its summary lines and its specialists' code-tool results, not the raw data.

Bringing a farm online

The onboarding assistant is the most capable model we can reach. The farmer talks; it asks follow-ups, looks up the place and the weather, and structures the answers.

How often each part runs

10 s
Sensor set → master → laptop

Every reading is stamped, written to the SD card and posted to POST /log. The master checks it against the ranges and switches the pump if needed.

5 min
Master checks the ranges

GET /ranges/version: a new plan is downloaded and saved to the SD card only when the version changes. Daily is enough for the product.

6 h
Agent run (or Run now)

00:00, 06:00, 12:00, 18:00. About 4–6 minutes with local models: the summariser, 5 departments, the Director, the Arabic message, the code check.

once
Onboarding

When a farm joins, and again when a crop, field or sensor changes.

Who decides what

Code counts and checks

The summariser and the code tools compute every number. The code check clamps every range inside the hard limits set at onboarding and flags it. The master's firmware decides what each range means.

Agents judge and explain

Departments turn the numbers into reports, and the Director turns them into one plan and a message for the farmer. The farmer approves or corrects the advice, and that log becomes the fine-tuning data for the final product.
